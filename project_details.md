# prototype-space

Where an idea becomes something you can watch run.

## What it is

An open-source space for turning an idea into a working prototype — one that someone
else can pull down and run for themselves.

Most ideas die in the gap between "wouldn't it be cool if" and the first thing that
actually runs. prototype-space exists to close that gap. Bring an idea, leave with
something visible.

## What counts as a prototype

A simulation. A script. A dashboard. A rig on a desk. A robot.

If it runs, and someone else can run it, it counts. A simulation is not a lesser
prototype than a machine — it is often the fastest honest way to find out whether an
idea holds up.

## Who it's for

Developers. Anyone who would rather build the rough version than write the long
proposal.

This is a RoBonn project, so robotics is the culture you'll find here — but it's the
culture, not the entry requirement. Bring whatever you're trying to make real.

## How it works

Build the smallest version that runs. Put it somewhere others can reach it. Show it.

Then do it again, less roughly.

## Where this is going

This is early. What's here today is the idea and the intent — the tooling, templates
and shared parts come next, built by the people who show up to use them.

The longer-term vision is an open platform with shared hardware, software and data.
Treat that as the horizon, not as a description of what exists yet.
